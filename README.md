# Nexora
### Control total para tu empresa en un solo lugar

**Nexora** es un sistema ERP (Enterprise Resource Planning) diseñado para **pequeños comercios y empresas**, cuyo objetivo es centralizar la gestión empresarial en una única plataforma web.

Permite a los negocios gestionar de forma sencilla aspectos clave como:

- clientes
- productos
- inventario
- ventas
- usuarios del sistema

De esta forma, Nexora ayuda a mejorar la **organización del negocio, el control del stock y la toma de decisiones**, reduciendo el tiempo dedicado a tareas administrativas.

---

# Objetivos del proyecto

El objetivo principal de **Nexora** es desarrollar una aplicación web que permita a pequeños negocios gestionar sus operaciones diarias de manera **eficiente, intuitiva y accesible desde cualquier dispositivo**.

## Objetivos específicos

- Centralizar la información de la empresa en una única plataforma.
- Facilitar la gestión de clientes y proveedores.
- Controlar el inventario en tiempo real.
- Registrar y gestionar ventas o pedidos.
- Proporcionar estadísticas básicas para el negocio.

---

# Módulos principales

## Gestión de usuarios

Permite controlar quién puede acceder al sistema.

### Funciones

- registro de usuarios
- inicio de sesión
- gestión de roles (administrador / empleado)

---

## Gestión de clientes

Permite registrar y consultar la información de los clientes.

### Funciones

- crear clientes
- editar clientes
- eliminar clientes
- buscar clientes

### Datos almacenados

- nombre
- teléfono
- email
- dirección
- empresa

---

## Gestión de productos

Permite administrar el catálogo de productos.

### Funciones

- crear productos
- editar productos
- eliminar productos
- consultar stock

### Datos almacenados

- nombre
- descripción
- precio
- categoría
- cantidad disponible

---

## Gestión de ventas / pedidos

Permite registrar las ventas realizadas.

### Funciones

- crear pedidos
- añadir productos al pedido
- calcular el total automáticamente
- asociar el pedido a un cliente

---

## Gestión de inventario

Permite controlar el movimiento de productos dentro del negocio.

### Funciones

- registro de entradas de stock
- registro de salidas de stock
- historial de movimientos
